日期：2026-10-08。本文件说明代码和预检；本地未启动正式训练，尚无三个任务的新成绩。

## 执行范围与冻结设置

仅运行原始BatLiNet、基础潜在交叉注意力、循环轴残差增强版。按MATR-1、HUST、MATR-2串行执行；每任务按种子0—7、每种子三个模型，共72次训练，每次1000轮。MATR-1和MATR-2分别训练，不共享权重。所有模型从同种子随机初始化；不加载其他任务或历史权重，不增设其他变体。

九份配置位于 `configs/three_tasks_v1/<任务>/<模型>.yaml`。主入口 `scripts/run_three_tasks.py` 使用现有三模型的前向、预处理和损失接口，不使用旧入口的训练中测试或编译流程。

## 与官方、历史训练的明确差异

- 官方三个任务默认开启循环过滤，本版本三模型统一关闭，以匹配已有潜在／循环轴六通道主线；仍保留各模型原有容量轴边缘和毛刺清理。原始模型先构造自身／跨电池差分再清理；两个潜在模型先清理原始输入，再分别编码，不套用原始模型差分基准。
- 物理批量16降低显存占用，逻辑批量仍128。每个物理分批损失乘以本分批样本数／当前逻辑批样本数，每逻辑批更新一次。物理分批改变相对整批训练的随机失活调用调度。
- 训练参考采用独立CPU随机数生成器，种子等于训练种子，按逻辑批一次抽取，有放回抽样，允许自身参考；同任务同种子三模型抽取轨迹相同，不受不同模型的随机失活耗随机数影响。每100轮不再推进旧测试监测随机数，本版本不声称逐位复现历史训练。
- 测试固定32参考，生成器种子为训练种子加200000；同任务同种子三模型共享文件及电池顺序。重复参考保留，全部参考来自有效训练池。测试分块8个参考计算，合并32个预测后取PyTorch较小中位值，绝不对分块中位数再平均。
- 每任务24次训练全部完成后，才用固定1000轮权重测试该任务。测试不选轮次、种子或配置。之后继续下一任务。
- 关闭即时编译和两种TF32开关，使用确定性的cuDNN设置；不保证跨硬件或不同软件版本逐位一致。

因此原始模型与潜在模型是完整方法比较；基础潜在与循环轴版是同条件结构对照。新增任务结果不能直接当作旧MIX批次的逐位复现。

## 在服务器一次后台启动

使用已有服务器环境，不安装或升级依赖：

```bash
cd /root/autodl-tmp/BatLiNet-cycle-mixer && \
conda activate batlinet && \
git switch agent/cycle-mixer-latent-cross-attention && \
git pull --ff-only origin agent/cycle-mixer-latent-cross-attention && \
bash scripts/start_three_tasks_nohup.sh /root/autodl-tmp/BatLiNet-main3
```

启动器内部执行 `nohup python -u ... >独立日志 2>&1 </dev/null &`。一次启动顺序跑三个任务；关闭本地电脑、网页、SSH终端或网络中断不影响后台进程，服务器必须保持运行。数据默认来自 `BatLiNet-main3/data/processed/MATR` 和 `BatLiNet-main3/data/processed/HUST`。

启动器记录进程号和日志路径，并在两秒后检查进程是否仍活着。这只确认进程存在，**不代表预检已通过**。Linux队列文件锁拒绝重复启动，同目录旧进程活着时启动器也会拒绝。

查看当前日志：

```bash
cd /root/autodl-tmp/BatLiNet-cycle-mixer
LOG=$(cat workspaces/three_tasks_three_models_v1/latest_log.txt)
tail -f "$LOG"
```

按Ctrl+C只退出查看日志，不停止后台训练。查看机器可读状态：

```bash
cat /root/autodl-tmp/BatLiNet-cycle-mixer/workspaces/three_tasks_three_models_v1/status.json
```

如需只做服务器数据和显存预检，可在尚未运行队列时使用：

```bash
python -u scripts/run_three_tasks.py --source-root /root/autodl-tmp/BatLiNet-main3 --prepare-only
```

正常全队列已经包含同样预检，无须先跑一次。所有三个数据集、24份固定参考和九组实际训练前向／反向显存检查通过后才训练。显存预检的评价查询使用训练电池，不读取测试成绩。数据缺失、名单不符、非有限值、显存不足或元数据冲突会停止；不会自动减批量、改精度、跳种子或忽略失败。失败详情在日志和 `status.json`。需要协助时发送失败日志最后80行以及 `status.json` 内容。

## 恢复、文件绑定和产物

默认目录 `workspaces/three_tasks_three_models_v1/`，与历史MIX目录分开。代码、配置、Git提交、运行环境或原始文件变化时拒绝复用已有队列；不要在同目录中混用新协议。

每次训练先保存第0轮状态，每25轮原子替换 `progress.pt`，包含模型、优化器、Python／NumPy／PyTorch／当前GPU随机状态以及训练参考生成器状态。异常停止或服务器重启后，在相同环境、数据、代码和配置下**重新执行启动命令**，从最近已保存轮次恢复；最多重做未保存的24轮。训练日志中超出检查点的部分先另存为 `interrupted_log_*.jsonl`。环境相同的CPU合成数据中恢复权重已验证逐项相等；GPU恢复仍需服务器执行。

`final.pt` 保存固定1000轮模型权重及完整绑定元数据，不含优化器；`progress.pt` 保留最终优化器和随机状态。完成训练核对权重轮次、日志和绑定后跳过；已有测试重新核对权重指纹、实际参考、真值、分支组合和指标。数据缓存及参考协议均限权加载，文件写入先写临时文件再原子替换，保留历史产物。

```text
workspaces/three_tasks_three_models_v1/
  queue.json                   # Git提交、源码指纹、环境、九配置
  preflight.json               # 实际有效数量、九组梯度／显存预检
  status.json                  # 最近任务／轮次，完成或失败状态
  logs/                        # 每次启动的独立后台日志
  datasets/<任务>/
    data.pt                    # 原始六通道输入、寿命、名单、训练标签统计
    receipt.json               # 数据身份、排除名单、实际有效计数
  protocols/<任务>/seed_*.pt    # 跨三模型共用的固定32参考
  <任务>/<模型>_seed*/
    run.json
    train.jsonl                # 每轮训练损失、耗时、优化器步数、显存峰值
    progress.pt                # 恢复用模型＋优化器＋随机状态
    final.pt                   # 固定最终权重
    test.pt                    # 循环单位预测／真值、标准化对数单位分支及32参考诊断
  per_seed.json / per_seed.csv
  summary.json                 # 三任务三模型，八种子均值和样本标准差
```

均方根误差（RMSE）和平均绝对误差（MAE）单位为循环；平均绝对百分比误差（MAPE）、15%以内准确率（ACC15）为小数，后者判断相对误差≤0.15。指标使用双精度归约，不按表现筛种子。全部72份预测通过核验后状态才写为complete。大文件在工作区内已被Git忽略，不推送数据或权重。
