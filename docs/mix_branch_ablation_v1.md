# MIX 分支消融实验

本批次比较当前循环轴残差与软匹配潜在差分组合模型的两条预测分支。MIX-20、MIX-100 各用种子 0—7，分别从头训练完整模型、仅自身分支、仅参考分支，共 48 次训练。两个单分支按相同任务、相同种子直接组成独立集成，不再训练，共形成 64 份评价。已有历史训练成绩不充当本轮完整模型对照。

## 模型及损失

三个训练模型均由同种子的完整、未训练组合模型初始化，再移除不参与的分支；不加载历史训练权重。公共编码器及保留模块的初始参数一致。

| 设置 | 结构 | 训练损失 | 测试输出 |
| --- | --- | --- | --- |
| `full` | 共享编码器、自身预测头、软匹配差分及关系预测头 | 0.5 × 自身损失＋0.5 × 参考损失 | 两分支等权融合 |
| `self_only` | 循环轴残差编码器及自身预测头 | 0.5 × 自身损失 | 自身预测 |
| `reference_only` | 目标与参考共享编码器、软匹配差分及关系预测头 | 0.5 × 参考损失 | 参考聚合预测 |
| `independent_ensemble` | 上述两个独立训练模型 | 不训练 | 两份单分支预测等权融合 |

训练损失权重和测试输出选择分别控制；单分支的损失系数为 0.5，不代表把预测寿命减半。关系分支仍须输入目标与参考电池，根据预测寿命差加上参考已知寿命得到目标预测。训练的两个参考取均值，测试的固定 32 个参考取中位数。融合在历史标准化自然对数寿命空间进行，反变换后输出循环数。独立集成有两套编码器，评价时同时记录模型参数量。

## 固定实验协议

| 项目 | MIX-20 | MIX-100 |
| --- | --- | --- |
| 有效训练／测试电池 | 207／147 | 205／137 |
| 输入 | 六通道，前 20 循环，第 11 循环置零 | 六通道，前 100 循环 |
| 每循环容量采样点 | 1000 | 1000 |
| 寿命终点 | 额定容量的 90% | 额定容量的 80% |
| 种子 | 0—7 | 0—7 |
| 训练轮数及权重选择 | 固定第 1000 轮，无验证集选轮 | 同左 |
| 逻辑／物理批量 | 128／128 | 128／16 |
| 训练／测试参考数 | 2／32，涉及参考的设置适用 | 同左 |
| 精度及优化器 | 单精度，AdamW，学习率 0.001，权重衰减 0.01 | 同左 |

输入清理、历史标签变换和电池划分沿用已有混合任务。训练不打乱电池顺序，参考从训练池有放回抽取；单独使用种子加 310000 的 CPU 随机数生成器，避免网络随机失活或分支删除改变参考抽样。各设置的参考抽样序列一致；仅自身模型不使用参考输入。测试参考复用历史实际固定的 32 个索引，不重新抽取。

先核对两个任务的历史数据和八种子测试协议，再完成训练用数据的真实显存、前向及梯度预检。所有 48 次固定轮数训练完成并通过完整性核对后，才统一进行最终测试，不使用测试成绩挑选轮次、种子或设置。

每 25 轮保存模型、优化器和恢复所需全部随机状态。恢复要求源码、提交、配置、数据、参考协议和运行环境绑定一致，拒绝混用已有输出；中断后重新执行相同启动命令即可恢复，最多重做未保存的 24 轮。

## 服务器启动

```bash
cd /root/autodl-tmp/BatLiNet-cycle-mixer
conda activate batlinet
git switch agent/cycle-mixer-latent-cross-attention
git pull --ff-only origin agent/cycle-mixer-latent-cross-attention
bash scripts/start_mix_branch_ablation_nohup.sh
```

启动脚本内部使用 `nohup`，关闭标准输入、合并日志，调用后会返回终端，不需要外层再加 `nohup` 或 `&`。可以关闭终端、断开连接或关闭本地电脑；服务器须保持运行。启动后两秒只检查入口是否仍存活，预检通过以日志为准。

默认历史目录为 `/root/autodl-tmp/BatLiNet-main3`，原始目录为 `/root/autodl-tmp/BatLiNet-main2`，本批输出为代码根目录下的 `workspaces/mix_branch_ablation_v1`。可通过三个位置参数覆盖路径，通过环境变量选择解释器和设备：

```bash
PYTHON_BIN=python DEVICE=cuda:0 bash scripts/start_mix_branch_ablation_nohup.sh \
  /root/autodl-tmp/BatLiNet-main3 \
  /root/autodl-tmp/BatLiNet-main2 \
  /root/autodl-tmp/BatLiNet-cycle-mixer/workspaces/mix_branch_ablation_v1
```

启动命令由文件锁串行保护，重复运行以队列锁判断，不会因为旧进程号被系统复用而误报。入口还会取得当前设备的 GPU 队列锁。同 GPU 的旧实验入口未参与本锁，启动前须确认没有其他训练任务占用该设备；脚本不会终止其他进程。

只准备数据、参考和真实数据显存／梯度预检，不启动正式训练：

```bash
python -u scripts/run_mix_branch_ablation.py --prepare-only
```

该命令同样使用默认路径和 `cuda:0`，可显式传入 `--history-root`、`--original-root`、`--workspace`、`--device`。正式准备及训练须在有 CUDA 的 Linux 服务器运行。

## 进度及结果

```bash
tail -f "$(cat workspaces/mix_branch_ablation_v1/latest_log.txt)"
cat workspaces/mix_branch_ablation_v1/status.json
```

在 `tail -f` 中按 Ctrl+C 只退出查看，不停止训练。训练错误会停止队列并写入状态及日志，不自动缩小批量、切换精度或跳过失败种子。

```bash
python scripts/run_mix_branch_ablation.py --report
```

`--report` 只读取已保存的汇总并校验结果范围，不启动训练、不重新推理，也不要求 CUDA。指定其他工作区时加 `--workspace /绝对路径`。

输出保存在独立工作区，包含来源及运行绑定、历史数据与参考协议、预检与进度状态、逐轮训练日志、可恢复检查点、最终权重、四种设置的逐电池测试结果及逐种子／总体汇总。独立集成也单独保存 `test.pt`，可追溯到对应两个单分支。

汇总报告均方根误差（RMSE）、平均绝对误差（MAE）、平均绝对百分比误差（MAPE）和相对误差 15% 以内准确率（ACC15）的八种子均值与样本标准差，并记录同种子配对差。RMSE、MAE 单位为循环，MAPE、ACC15 为比例。完整模型的两条分支读出仅作为诊断，正式单分支消融以重新训练的两个模型为准。

本批独立参考随机数流不同于旧训练入口，因此本轮四种设置构成新的统一对照；旧批次结果仅作历史背景。
