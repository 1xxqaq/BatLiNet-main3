# 跨化学体系迁移：逐次训练停止对照 v5

本版比较目标直接训练、LFP预训练后微调、循环轴残差与软匹配差分组合三种方法。全部344次训练从头执行，均采用最大1000次参数更新、每50次评估、最早100次后允许停止、连续5次误差未严格下降则停止，并保留该次训练误差最低的权重。这里的“误差”依据方法分别定义，不能将全部方法表述为独立验证早停。

本版没有32次LFP开发阶段，没有从开发最佳步数汇总固定预算，也不留出40块LFP。275块LFP继续全部用于来源预训练与组合模型参考。已有v3、v4结果与代码分别保留，v5不加载其模型权重作为初始化。

## 数据与只读来源

- 默认上一版本目录为`workspaces/cross_chem_matched_v3`。只读复用实际目标名单和已保存的学习率，不重新搜索学习率。
- 读取v3的112份目标协议：LCO、NMC训练数量为1、2、4、8、16，NCA为1、2、4、8；各种子0—7。训练电池与测试电池名单、顺序保持一致，同种子跨档位训练子集仍然嵌套。
- 特征从v3队列身份的`existing_workspace`所指向的v2缓存读取：275块LFP、37块LCO、22块NCA、69块NMC。固定目标测试数量分别为21、14、53。
- 组合模型复用底层协议实际保存的80%训练电池对与20%验证电池对，不重新随机划分。导入时按目标与来源电池编号换算索引，避免旧协议与当前模型展平顺序不同导致错配。
- 标签统一为自然对数`ln(T/1000)`，特征仍为前100循环、六通道、1000个容量位置，绝对值超过10的特征置零。

组合模型在当前已选n块目标训练电池与275块LFP之间组成全部电池对，其中80%仅用于梯度训练，剩余20%仅用于监控停止。目标测试电池完全不进入该过程。n为1时共有275对，220对训练、55对验证；训练与验证共享该目标电池，只是参考配对不同。

## 各阶段监控指标

| 阶段 | 监控指标 | 数据性质 |
| --- | --- | --- |
| LFP来源预训练 | 275块LFP的对数寿命预测均方误差 | 训练电池误差 |
| 目标直接训练 | 已选n块目标电池的对数寿命预测均方误差 | 训练电池误差 |
| 目标微调 | 已选n块目标电池的对数寿命预测均方误差 | 训练电池误差 |
| 组合模型 | 留出20%电池对上的关系差分对数均方误差 | 共享目标训练电池的关系对验证误差 |

评估时关闭随机失活，不计算梯度，并隔离评估对随机数和训练模式的影响。组合的关系误差等价于“关系头预测的寿命差＋来源对数寿命”与目标对数寿命之间的均方误差；不使用最终融合误差选择权重。其训练损失仍为自身回归与关系回归各占一半。

当前组合结构共享编码器并联合训练两个回归头，因此关系验证指标决定的是整个组合模型的停止时间和最佳快照，并非两个分支分别早停。直接训练、来源预训练及微调没有独立验证电池，应称为“训练误差停滞停止”。这种规则不能证明避免了过拟合，特别是n为1时模型可能持续拟合训练电池而最终跑满1000次。

## 停止与权重规则

| 参数 | 固定值 |
| --- | --- |
| 最大优化器更新次数 | 1000 |
| 首次评估 | 第50次更新后 |
| 后续评估频率 | 每50次更新 |
| 允许停止的最小更新次数 | 100 |
| 耐心值 | 连续5次评估未严格改善 |
| 改善判定 | 新误差严格小于此前最佳误差，不设额外改善阈值 |
| 最终权重 | 监控误差最低时的权重；相等时保留先出现的权重 |

不执行第0步评估。第50步建立初始最佳记录，因此它可以是最终最佳步数，即使训练要在100步后才允许停止。若从首次评估起误差始终不改善，则第300步停止。触及1000步时停止原因记为`max_steps`，即使该步也满足耐心条件；最终仍使用全过程的最佳权重。

每个种子单独训练一份来源预训练模型。该种子的14个目标微调任务分别从其最佳来源权重初始化，各自重建优化器，不接续上一数量或体系的微调结果。

## 数量、测试与解释边界

全部执行8次来源预训练与112个目标场景×3种方法，共344次全新训练。此次不复用v3两个单电池基线的权重，因为停止规则已改变。全部训练完成且通过权重、收据和来源核验后，才统一计算336份目标测试预测。

组合测试继续使用全部275块来源参考，关系预测取中位数，再与自身预测在对数寿命空间各占一半融合。汇总原有四项指标、8种子均值与样本标准差，以及同种子配对差异。不会根据测试结果选择停止点、排除种子或修改规则。

三种方法采用相同停止参数，但监控数据性质不同，不应表述为相同独立验证条件或等总算力。微调包含来源预训练和目标微调两个阶段，应分别记录更新次数与耗时。与v3比较时，组合同时改变了训练对比例与权重选择方式，成绩差异不能全部归因于早停或网络结构。

各次训练保存`monitor_policy`、`best_step`、`trained_steps`、`best_loss`、`stop_reason`、`hit_max_steps`及完整监控历史。最佳权重与终止时的恢复状态分别保存；恢复状态包含当前权重、优化器、随机数、采样游标、最佳权重和耐心计数。

## 部署与运行

服务器使用独立工作树运行，保留旧目录当前提交，避免改变其他实验的代码及恢复身份。将下面的`<本次分支>`与`<本次提交>`替换为实际交付值：

```bash
cd /root/autodl-tmp/BatLiNet-cycle-mixer
git fetch origin <本次分支>
git worktree add --detach /root/autodl-tmp/BatLiNet-cross-chem-earlystop-v5 <本次提交>
cd /root/autodl-tmp/BatLiNet-cross-chem-earlystop-v5
bash scripts/start_cross_chem_earlystop_v5_nohup.sh \
  --previous-workspace /root/autodl-tmp/BatLiNet-cycle-mixer/workspaces/cross_chem_matched_v3
```

启动脚本内部使用`nohup`，自动进入`batlinet`环境，将`OMP_NUM_THREADS`与`MKL_NUM_THREADS`设为8。默认输出位于新工作树的`workspaces/cross_chem_earlystop_v5`，进程号保存在`queue.pid`，最近日志路径保存在`latest_log.txt`。

```bash
tail -f "$(cat workspaces/cross_chem_earlystop_v5/latest_log.txt)"
```

可先只检查来源和准备新队列，不开始正式训练；报告命令只读运行：

```bash
bash scripts/start_cross_chem_earlystop_v5_nohup.sh \
  --previous-workspace /root/autodl-tmp/BatLiNet-cycle-mixer/workspaces/cross_chem_matched_v3 --prepare-only
bash scripts/start_cross_chem_earlystop_v5_nohup.sh \
  --previous-workspace /root/autodl-tmp/BatLiNet-cycle-mixer/workspaces/cross_chem_matched_v3 --report
```

可通过`--workspace`指定独立新结果目录，通过`--device cuda:0`指定设备。没有开发阶段，因此不提供`--pilot-only`。

启动器检查当前工作树、v3所在工作树，以及已知兄弟工作树`BatLiNet-cross-chem-earlystop-v4`、`BatLiNet-cross-chem-earlystop-v5`的已知队列锁。旧锁文件只读打开，其他训练持有排他锁时拒绝启动，不停止旧进程，不修改旧锁。该检查较保守：即使指定另一设备，已知队列仍在运行时也会拒绝。

中断后进入已创建的新工作树，重复同一启动命令恢复，无需再次创建工作树。当前代码、运行环境、来源文件、实际名单、电池对顺序和检查点绑定必须一致。不要通过删除旧结果、改写名单或改动旧选择文件绕过检查。
