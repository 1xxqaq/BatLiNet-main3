# 同编码器单电池跨化学体系对照（2026-10-14）

用户授权只准备本模型单电池版的直接目标训练、LFP监督寿命预训练后微调。已有原始作者迁移复跑只作大致参考，本入口不补训、不汇总该原始模型；保留已有完整组合作参考比较。MATR-1、HUST、MATR-2以及MIX-100单差分继续暂缓。

## 结构与冻结训练协议

复用现有组合模型的cell_encoder（卷积编码器、位置参数、隐藏宽16的循环轴残差）及ori_head；用相同种子初始化时这两部分权重逐元素相同。不保留软匹配差分、关系回归头或参考聚合；不改变现有组合代码。

- 输入：前100循环、原六通道、1000个容量位置；编码前绝对值大于10置0，不做第10循环自身差分。
- 寿命目标：固定变换ln(寿命循环数/1000)，反变换exp(输出)*1000。1000是预先固定的单位，未从LFP、目标训练或测试标签估计均值／标准差；单目标也可训练。该单位不是训练轮数。
- 直接目标：新随机初始化，仅选中目标电池自身寿命损失训练。
- 预训练微调：各种子在全部275个LFP监督寿命预训练；保留编码器和自身头，目标每个档位／种子都独立加载该种子同一来源权重，创建新的AdamW并更新全部参数。不依次接着其他目标微调，不用MIX旧权重。
- 三阶段各固定100轮，使用第100轮最终权重，不设早停，不用目标测试选轮次。目标仅1块时无法构造独立电池验证集，故固定预算。
- AdamW，学习率0.001，权重衰减0.01，逻辑批32、物理批8，不打乱，与当前作者自身分支的固定预算及优化器数量级一致；两个新对照设置相同。来源275块每轮9次更新，目标每轮1次更新；不称三方法更新预算完全一致。
- 单精度，保留现有编码器与回归头的0.1丢弃率；八种子全部保留，预测溢出报错，不截断或按性能删种子。
- 各种子LFP预训练100轮，共8次；三目标14档×8种子×两对照=224组目标结果，共232个训练阶段。NCA最多8块，不运行16块。

## 恢复、预计结束时间和文件

新工作区workspaces/cross_chem_single_cell_v1，训练与旧队列互斥。已有特征及预测仅读取，锁文件是运行协调例外。首次核验所有缓存并用丢弃的临时模型检查前向、梯度和显存，测量275、1及最大目标子集每轮耗时；正式运行前失败则停止。
